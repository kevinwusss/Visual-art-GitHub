# Master's application portfolio notes

Use these as a draft and revise any first-person claim to reflect work you personally did. Avoid stating a measured outcome until you have data to support it.

## Short English description (approximately 100 words)

Visual art is a bilingual fashion styling prototype that connects a digital wardrobe with outfit recommendations, weather and editorial discovery. I built it to explore how personal data can be translated into useful, explainable product decisions. The Next.js and TypeScript application stores wardrobe information locally, ranks garments with a rules-based styling engine, and optionally enriches results through external AI and search services. The interface identifies whether a result is live, locally computed or curated. The project strengthened my skills in full-stack development, state design, API integration, interface design and testing. Its next step is a small user study to evaluate recommendation usefulness.

## 中文简介

Visual art 是一个中英双语的数字衣橱与穿搭原型。它把衣橱单品、场景和天气结合起来，生成穿搭建议，并加入时尚内容和商品发现。项目使用 Next.js、TypeScript 和本地状态管理；核心推荐由可解释的规则实现，外部 AI 与搜索服务为可选增强。界面会标注结果来源。我希望进一步通过用户研究评价建议是否真正有用，而非仅以功能数量判断效果。

## Good evidence to add before an application

- Three clear screenshots, ideally desktop homepage, wardrobe and stylist result; verify captions and image publication rights first.
- A brief account of your own role, design decisions, bugs solved and what you would change after user testing.

## Suggested interview discussion

Why was a local ranking engine useful as a fallback? What information belongs in browser storage versus a database? How does the UI communicate source and uncertainty? Which metrics would you collect, with consent, to assess recommendation quality?
